# Results format

## `runs-index.csv`

One row per container run, appended by `runner/run-series.sh`. Never delete rows of failed runs —
add a note instead; failed and repeated runs are part of the methodology.

| Column | Meaning |
| ------ | ------- |
| `run_id` | UTC start timestamp, `YYYYMMDDTHHMMSSZ` — also the directory name |
| `series` | `A`, `B`, `C`, `D`, `E`, `F`, `Fgc`, `G`, `SMOKE` |
| `case` | benchmark case, e.g. `react-10k`, `react-5k-hub`, `react-10k-r7` |
| `tools` | tool ids passed in `TOOLS` |
| `run_times`, `warmup_times` | measured and warm-up iterations |
| `mem`, `cpuset` | container memory limit and CPU set |
| `exit_code` | exit code of `pnpm benchmark` |
| `oom_killed` | Docker `State.OOMKilled` of the container's main process |
| `cgroup_oom_kills` | `oom_kill` counter from `memory.events` — counts kills of *any* process in the container (bundler, Chrome) |
| `started_utc`, `finished_utc`, `duration_s` | wall clock |
| `git_sha`, `image_id` | exact code and image that produced the data |
| `vm_size` | VM size from `env/latest/vm.json` |
| `path` | relative path of the run directory |
| `note` | free text (deviations from protocol, reruns) |

## `module-counts.jsonl`

Graph size of each case from a webpack development build (`runner/count-modules.sh`):
`modules_total` (|V| without webpack runtime modules), `modules_src`, `modules_node_modules`,
`edges_reasons` (number of import reasons — an approximation of |E|). X axis of the series D regression.

## `raw/<series>/<case>/<run-id>/`

Directory names of series: `A-replication`, `B-main`, `C-hub`, `D-scaling`, `E-network`,
`F-stress-2g`, `F-gc-trace`, `G-artifacts`, `_smoke`.

| File | Producer | Content |
| ---- | -------- | ------- |
| `environment.json` | `scripts/benchmark.ts` | Node, platform, CPU model, warm-up/run counts, timeouts |
| `<iter>-<tool>-<timing\|memory>-<phase>-attempt-<n>.json` | `scripts/benchmark.ts` | every single measurement, including warm-ups (`"warmup": true`) |
| `runs.json` | `scripts/benchmark.ts` | metrics of every iteration, per tool |
| `attempts.json` | `scripts/benchmark.ts` | successful and failed attempts with error text |
| `summary.json`, `summary.md` | `scripts/benchmark.ts` | median/min/max over measured iterations, sizes |
| `console.log` | `run-series.sh` | full stdout/stderr of the container |
| `run-meta.json` | `run-series.sh` | all run parameters + Docker `State` |
| `cgroup-memory.events`, `cgroup-memory.peak` | cgroup v2 | OOM counters and container-level peak memory (bytes) |
| `cgroup-cpu.max`, `cgroup-cpuset.txt` | cgroup v2 | CPU quota and effective CPU set |

Iteration indices `0 … warmup_times-1` are warm-ups and must be excluded from statistics.

## `../data/` (derived)

Generated by `analysis/` from `raw/`; tidy "long" format, one measurement per row:

`series, case, run_id, tool, config, iteration, metric, phase, value, unit`

Regenerate instead of editing.
